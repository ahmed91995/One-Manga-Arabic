# مانجا ون — Manga One

واجهة عربية داكنة لقراءة المانغا والمانهوا. تتضمن مكتبة بحث وتصنيفات، تفاصيل العمل، قارئ الفصول، ولوحة إدارة لإضافة الأعمال والفصول ورفع صورها إلى Supabase.

## تشغيل المشروع

1. ثبّت Node.js (إصدار حديث) على الكمبيوتر.
2. افتح مجلد المشروع في محرر أو بيئة تطوير.
3. نفّذ `npm install` ثم `npm run dev`.
4. لنسخة النشر نفّذ `npm run build`.

## تفعيل حفظ الأعمال والفصول أونلاين

حتى تكون الأعمال والفصول متاحة لكل الزوار، تحتاج قاعدة بيانات وخدمة صور على الإنترنت:

1. أنشئ مشروعاً في Supabase.
2. من SQL Editor شغّل الملف `supabase/setup.sql`.
3. من إعدادات المشروع انسخ Project URL و anon/public key إلى ملف `.env` اعتماداً على `.env.example`.
4. أنشئ حساب إدارة من Supabase Authentication > Users.
5. افتح لوحة الإدارة من زر «إدارة المحتوى» وسجّل الدخول بهذا الحساب.
6. ارفع غلاف كل عمل وصور الفصول من لوحة الإدارة.

**مهم:** لا تضع `service_role` key في واجهة الموقع. استخدم فقط anon/public key، واترك صلاحيات التعديل لحساب موثّق.

## الظهور في Google

الملفات `robots.txt` و`sitemap.xml` موجودة كبداية. بعد نشر الموقع على استضافة عامة:
- استبدل `YOUR-DOMAIN.example` في الملفين بنطاقك الحقيقي.
- أضف النطاق إلى Google Search Console وأرسل `sitemap.xml`.
- قد يحتاج Google وقتاً لفهرسة الصفحات، ولا يمكن ضمان الظهور أو ترتيب محدد.
- هذا مشروع واجهة React أولية؛ إذا أردت فهرسة مستقلة قوية لكل عنوان وفصل، يُفضّل لاحقاً نقله إلى إطار يدعم العرض من الخادم مثل Next.js.

## ملاحظات

- من دون إعداد Supabase، يعمل الموقع ببيانات تجريبية محلية؛ أي إضافات محلية ليست منشورة للزوار.
- ارفع فقط المحتوى الذي تملك حق نشره أو لديك إذن بنشره.
